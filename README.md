# MecanAI Completo

Projeto completo com **Frontend + Backend** do MecanAI.

## Backend
- Node.js + Express
- Autenticação JWT
- Limites de planos (Free, Pro, Team)
- Integração com IA (OpenAI GPT)
- Banco de dados SQLite via Prisma

## Frontend
- Copie todo o frontend Lasy AI para a pasta `frontend`
